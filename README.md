# NIP rent

Aplikacja do rozliczania najmowanych mieszkań.

## Getting started

- Używając *Python3.12* utwórz *venv* i zainstaluj zależności

```sh
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Struktura projektu

main.py – główny plik programu Python.

data/ – folder zawierający dane mieszkań i najemców w plikach JSON.

requirements.txt – lista bibliotek potrzebnych do działania programu.

.gitignore – określa, które pliki Git ma ignorować.

.vscode/ – ustawienia edytora VS Code.
